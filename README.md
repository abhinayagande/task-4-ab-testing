
📊 Task 4 – A/B Testing

📌 About the Project

This project compares two groups (Ad and PSA) to check if the advertisement improved conversion rates using Python and statistical testing.

🎯 Objective

Compare ad vs control group
Calculate conversion rate
Perform t-test
Check if difference is significant

🛠️ Tools Used

Python
Pandas
Matplotlib
SciPy

📂 Dataset Columns

user id
test group (ad / psa)
converted (0 or 1)
total ads
most ads day
most ads hour

🧪 Hypothesis

H0: No difference in conversion rate

✅ Result

The t-test is used to decide if the ad campaign is effective or not.

H1: There is a difference
